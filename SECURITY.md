# Security

Agent2Pieces reads local coding-agent memory files and can send approved content to
a configured Pieces MCP endpoint. Review every candidate and destination before
using Apply. Do not import credentials, private keys, access tokens, personal
profiles, or material you are not authorized to store.

The web service binds to loopback and is intended for one local user. Do not expose
it through a proxy, public interface, or shared host.

## Reporting a vulnerability

Do not include secrets, private memory text, or exploit payloads in a public issue.
Use GitHub private vulnerability reporting for sensitive reports. For a regular
defect without private data, open a public issue.

This is an unofficial project and does not provide an official Mesh Intelligent
Technologies, Inc. support channel.
